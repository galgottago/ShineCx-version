# ShineCx-version

Gold-on-black demo site for **ShineCX** / Bobbi Jo Smith (Senior BAS & DDC Controls Specialist).

Original Shine repositories were not modified.

## Run

```bash
python3 -m http.server 8080
```

Open http://localhost:8080/

Pages: Home (operator dashboard), Services, About, Contact.

Near-black `#0a0a0a`, champagne gold `#D4AF37`. No Replit rainbow graphics.
